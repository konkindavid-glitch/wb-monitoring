# Шрифты для обложек

`DejaVuSans.ttf` и `DejaVuSans-Bold.ttf` — обложке нужен шрифт с кириллицей,
и найти подходящий оказалось сложнее, чем кажется:

- Arial, Segoe UI и прочие шрифты Windows кириллицу имеют, но они проприетарные.
  Репозиторий публичный, класть их сюда нельзя.
- Bitstream Vera свободен, но **кириллицы в нём нет** — вместо букв рисуются
  квадраты. Проверять наличие глифа по `getmask(...).getbbox()` бесполезно:
  у квадрата `.notdef` bbox тоже есть, и проверка проходит ложно. Сравнивать
  надо растр буквы с растром заведомо отсутствующего символа — так и делает
  `_renders_cyrillic()`.
- Скачать DejaVu напрямую не выходит: GitHub raw, jsdelivr и fonts.gstatic.com
  отдают HTML вместо файлов. Взято из колеса matplotlib, куда DejaVu входит
  целиком: `pip download matplotlib --no-deps`, дальше распаковка zip.

Лицензия — `LICENSE-DejaVu.txt`, распространение разрешено.

`monitoring/cover.py` ищет шрифт по списку: сначала эта папка, потом системные
пути контейнера. Найденный проверяется на кириллицу. Не нашёлся — обложка
не рисуется, карточка уходит текстом.
